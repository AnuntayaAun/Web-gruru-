04. PRODUCT INNOVATION // MODE 1

Data Booming: การระเบิดความรู้แบบนำทาง

Signature Interaction: เริ่มจากจุดเดียว แล้ว "ระเบิด" ออกเป็นความรู้ที่เชื่อมโยงกันทีละชั้น

HALL 02 // DATA BOOMING
01
เริ่มต้นจากจุดศูนย์กลาง (Single Seed Node)
หมดปัญหาอาการสับสน ผู้ใช้เริ่มจากประเด็นที่สนใจเพียงเรื่องเดียวตรงกลางหน้าจอ เพื่อโฟกัสความสนใจอย่างแม่นยำ
02
การระเบิดตามแนวรัศมี (Radial Burst 40ms)
เมื่อคลิก โหนดลูก 6–12 โหนดจะโผล่ออกมาเป็นวงรัศมีทีละโหนดห่างกัน 40ms เส้นเชื่อมลากพุ่งออกจากแกนกลางพร้อมวงแหวน Lime เรืองแสง
03
เจาะลึกได้สูงสุด 3 ชั้น (3-Level Deep Dive)
คลิกโหนดลูกเพื่อระเบิดชั้นถัดไป ตัวนับจำนวนความเชื่อมโยงวิ่งแบบสดๆ ให้เห็นเครือข่ายความสัมพันธ์ที่คาดไม่ถึง
04
สะพานเชื่อมสู่แผนที่เต็ม (Bridge to Interactive Graph)
เมื่อสำรวจความรู้ครบจังหวะ ระบบจะนำทางผู้ใช้เข้าสู่ Interactive Graph ฉบับเต็มเพื่อการสำรวจอิสระอย่างไร้รอยต่อ
